# Düymə olsa — logo (concept 02, the D icon)

The D's round counter is a push-button caught mid-press.

| Colour | Hex |
|---|---|
| Navy (background) | `#0B2545` / glow `#13396B` |
| Cream (D, name) | `#F4F1EA` |
| Coral (button) | `#FF5B4A`, lip `#B8352A` |
| Well (counter on navy) | `#071830` |

Type: Inter Display Bold, lowercase `düymə olsa`, outlined in every SVG.

- `svg/` editable sources: icon (+ light, mono white/navy), horizontal and stacked lockups
  (dark, light, transparent), `avatar.svg` (square, so the platform crops the circle), `endcard.svg`.
- `png/` exports of the same. Use `avatar-1080.png` as the profile picture.
- `Duyme_olsa_endcard_9x16.mp4` is the 3.6 s animated end-card (1080×1920, H.264 + AAC, soft click).
  `anim/endcard-preview.gif` is a small preview of it.
- Rebuild: `python3 build_final.py && node render_final.js`.
