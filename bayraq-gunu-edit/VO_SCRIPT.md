# Bayraq Günü Reel — səsləndirmə mətni (voice-over)

Aparıcı bu mətni sakit, isti və təmkinli səslə oxuyur, təxminən "radio xəbəri" yox,
"kino danışığı" tonunda. Hər cümlədən sonra kiçik pauza verin. Cümlələr ekrandakı yazılarla
eyni vaxtda gəlir. Ümumi müddət: ~31 s.

| Videoda vaxt | Mətn |
|---|---|
| 0:00 – 0:03 | Külək bayrağı dirəkdən qopardı. |
| 0:03 – 0:08 | Amma bir uşaq buna biganə qalmadı. |
| 0:09 – 0:13 | Külək güclü idi, dirək isə hündür. |
| 0:14 – 0:19 | O, dəfələrlə cəhd etdi. |
| 0:20 – 0:23 | Geri çəkilmədi. |
| 0:23 – 0:27 | Çünki bayrağa sevgi yaşla ölçülmür. |
| 0:27 – 0:31 | 9 Noyabr — Dövlət Bayrağı Günü mübarək! |

Yazılış qaydası: telefonda səs yazma tətbiqi kifayətdir. Sakit otaq, telefondan 20–25 sm
məsafə, səs-küy tutucusu söndürülmüş. Faylı (m4a/mp3/wav) göndərin — musiqinin altına
yerləşdirib səviyyəni balanslaşdırıram.
