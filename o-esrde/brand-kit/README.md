Highlight labels: BÖLÜMLƏR, ƏSRLƏR, KADR ARXASI, SUALLAR, HAQQIMIZDA, YENİ — change the `HL` list in
`src/build.py` to rename. Outro copy: "Sabah başqa əsrdə oyanırsan." + wordmark + "BİZİ İZLƏYİN".

Rebuild: `cd src && python3 build.py && node render.js && bash outro.sh`
(needs fonttools, numpy, Playwright/Chromium, ffmpeg). Fonts in `src/fonts/` are SIL OFL (Google Fonts).
