# Sözümün Canı — Reels archive

Cinematic 9:16 Reels (1080×1920, H.264/AAC) for the Araz Radio 103.3 FM segment «Sözümün Canı».
Each folder holds the final delivered video, its Reel cover, the original narration MP3 and the
editable project. Approved style rules and the user's feedback are in `../MEMORY.md`.

## Folder layout (per episode)

- `*_9x16.mp4` — final delivered export.
- `*_cover.jpg` — Reel cover (key content inside the profile-grid crop).
- `source/*.mp3` — the user's original narrated radio mix.
- `project/`
  - `index.html` + scene script (`film.js` / `melal.js` / `zen.js`), `common.js`, `cover.js` —
    the procedural canvas film; open `index.html` in Chrome and call `render(t)`.
  - `data.js`, `transcript_az.md` — corrected Azerbaijani transcript with word timings.
  - `logo.png`, `logo.js` — the supplied Araz Radio logo (cropped to the artwork, unaltered;
    embedded as a data URL so the canvas stays exportable).
  - `fonts/` — Google Fonts TTFs (SIL Open Font License).
  - `audio/` — Demucs-separated voice, original score, sound design (the final mix inputs).
  - `tools/` — render scripts (Playwright → ffmpeg), still previews, score/SFX generators.

Zənəxdan note: the final music is `project/audio/music.wav`, generated by
`tools/score_zen_music.py`. `tools/score_zen.py` generates the SFX (its music output is the
rejected first version).

`shared/` holds `audiolib.py` (shared synth/mix helpers used by the score scripts) and the logo
PNG exactly as the user uploaded it.

## Rebuild

1. Render frames: `node project/tools/render.js <abs path to project> <out dir> <duration>`
   (4 parallel Chromium pages piping PNG frames into libx264 segments), then concatenate the
   segments.
2. Mix: voice, music and SFX with gentle side-chain ducking, then loudnorm to −14 LUFS /
   −1.5 dBTP. The exact gains are in each project README.

Not included (cheap to recreate or superseded): intermediate high-quality render segments,
raw frames, earlier rejected versions, and the Demucs music-only stems.
