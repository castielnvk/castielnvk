# Sözümün Canı — «Məlal» (editable project)
- `melal.js` — all scenes, typography, timing (schedule: `SCENES` at the bottom). `common.js` — shared text/drawing helpers.
- `data.js` / `transcript_az.md` — corrected, word-timed transcript on the edited timeline (intro removed; original 12.78 s = 0:00 here).
- `logo.png` / `logo.js` — the supplied ARAZ Radio 103.3 FM logo, cropped to its artwork, unaltered (embedded as data URL for rendering).
- `audio/voice.wav` — narration isolated from the original mix with Demucs (htdemucs_ft), trimmed, 70 Hz high-pass only.
- `audio/music.wav`, `audio/sfx.wav` — original score and sound design, generated by `tools/score.py`.
- Fonts: Playfair Display, Lora (SIL OFL); captions in Inter.
Mix: voice −5 dB, music −11.8 dB with gentle side-chain ducking, sfx −7.3 dB, then loudnorm −14 LUFS / −1.5 dBTP.
