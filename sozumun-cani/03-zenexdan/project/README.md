# Sözümün Canı — «Zənəxdan» (editable project)
- `zen.js` — all scenes, typography and timing (schedule: `SCENES`); `cover.js` — the Reel cover; `common.js` — shared helpers.
- `data.js` / `transcript_az.md` — corrected, word-timed transcript on the edited timeline (original 12.5 s = 0:00; starts with Vidadi's lines).
- `logo.png` / `logo.js` — the supplied ARAZ Radio 103.3 FM logo, unaltered.
- `audio/voice.wav` — narration separated with Demucs (htdemucs_ft), trimmed, 70 Hz high-pass only.
- `audio/music.wav`, `audio/sfx.wav` — original score and sound design (`tools/score_zen.py`, needs `tools/audiolib.py`).
- Fonts: Fraunces (SIL OFL); captions/labels in Inter.
