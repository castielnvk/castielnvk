# Official logos (supplied by Araz FM)

These files are used exactly as supplied. Never redraw, recolour or retype them.

## `overlays/` — original files, 1080×1920 transparent PNG

These are the preferred source. The logos are already placed at the right size and in mobile-safe
positions: the programme logo upper left, Araz Radio upper right. Composite the overlay at
1080×1920 without scaling.

| File | Programme logo | Araz Radio logo | Use on |
|---|---|---|---|
| `100-seher-sousu_overlay_1080x1920.png` | 100% Səhər Şousu (yellow/purple) | teal | light or mid backgrounds |
| `biznes-merkezi_overlay_1080x1920.png` | Biznes Mərkəzi (dark blue) | teal | light backgrounds |
| `biznes-merkezi_overlay_white_1080x1920.png` | Biznes Mərkəzi (white) | white | dark backgrounds |
